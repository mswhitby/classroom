## 5–17 minutes · Skill 1: Increment and short-circuit logic

**Remember:**
- `a++` uses the old value, **then** increments.
- `++a` increments **before** using the value.
- With `||`, if the left side is true, Java does not evaluate the right side.
- With `&&`, if the left side is false, Java does not evaluate the right side.

### Guided trace

```java
int a = 5;
int b = 6;
if (a++ > b || b >= ++a) {
    System.out.print("yo");
}
System.out.print("wassup");
```

Fill in the table before checking:

| Expression | Value of a after evaluation | True/false |
|---|---|---|
| Initial state | 5 | — |
| `a++ > b` | ? | ? |
| `b >= ++a` | ? | ? |

**Predict the exact output:** __________

<details>
<summary>Guided answer</summary>

`a++ > b` compares 5 to 6 (false), then `a` becomes 6. Next, `++a` makes `a` equal 7; `6 >= 7` is false. The `if` body does not run. Output: `wassup`.

</details>

**Try it:** Change `b` to 4. Predict the output and final value of `a`. Explain which comparison Java skips.

### B. Spot the exception

```java
int[][] mat = new int[5][5];
for (int i = 0; i < mat.length; i++) {
    for (int j = 0; j < mat[i].length; j++) {
        mat[i][j] = i * j;
    }
}

for (int i = 0; i < mat[i].length; i++) {
    for (int j = 0; j < mat[i].length; j++) {
        mat[i][j] = mat[j][i];
    }
}
System.out.println(java.util.Arrays.toString(mat[3]));
```

**Discuss with a partner:**
1. Which row indices are valid?
2. What happens when `i` becomes 5 in the **second** outer loop's condition?
3. Does the program print a row, or throw an exception?
4. Rewrite the faulty condition so the loop finishes.

<details>
<summary>Check</summary>

Valid row indices are 0–4. Evaluating `mat[5].length` causes `ArrayIndexOutOfBoundsException` **before** the final print statement. Change the second outer loop condition to `i < mat.length`.

</details>

## 55–60 minutes · Contest strategy and exit ticket

Written-test scoring: **+6 correct, −2 incorrect, 0 unanswered**.

A guess has positive expected value only when your probability of being correct is greater than **25%**. If you can narrow a multiple-choice question to two or three plausible answers, answering is usually a better scoring decision than leaving it blank. First secure questions you know, mark time-consuming ones, scan the entire test for accessible questions, and return to harder problems.
