### Guided example: Q8

```java
int a = 5;
int b = 6;
if (a++ > b || b >= ++a)
    System.out.print("yo");
System.out.print("wassup");
```

Answer: **`wassup`** (D). The first condition evaluates `5 > 6` (false) and increments `a` to 6; the second increments `a` to 7 and tests `6 >= 7` (false). Change `b` to 4: the first comparison becomes true, so `||` short-circuits and the output is `yowassup`.

### Guided example: Q18

The second outer loop checks `i < mat[i].length` instead of `i < mat.length`. Once `i` reaches 5, evaluating `mat[5].length` throws `ArrayIndexOutOfBoundsException`. Correct answer: **E**. Fix the condition to `i < mat.length`; then discuss the row output.

## Timed mini-challenge (8 minutes, no IDE/calculator)

1. What prints?
   ```java
   String s = "bird";
   s.toUpperCase();
   System.out.println(s.substring(1, 3));
   ```
2. What prints?
   ```java
   int a = 2;
   if (a++ > 2 && ++a > 3)
       System.out.print("X");
   System.out.println(a);
   ```
3. What prints?
   ```java
   int n = 0;
   for (int i = 0; i < 4; i++)
       for (int j = 0; j <= i; j++)
           n++;
   System.out.println(n);
   ```
4. What prints?
   ```java
   int[][] a = {{1, 2, 3}, {4, 5, 6}};
   System.out.println(a[1][2]);
   ```
5. What prints?
   ```java
   Set<Integer> s = new HashSet<>();
   System.out.println(s.add(7));
   System.out.println(s.add(7));
   ```

**Coach key:** 1. `ir` (immutable string; substring end exclusive); 2. `3` (post-increment; short circuit); 3. `10` (1+2+3+4); 4. `6`; 5. `true` then `false` (duplicate rejected).

## Written-test strategy

Expected points for a random guess with probability `p` of being right: `6p - 2(1-p) = 8p - 2`. A guess is positive expected value when `p > 25%`.

| Remaining plausible answers | Probability if equally likely | Expected score |
|---:|---:|---:|
| 5 | 20% | −0.4 |
| 4 | 25% | 0 |
| 3 | 33.3% | +0.67 |
| 2 | 50% | +2 |

Students should first secure familiar problems, mark uncertain ones, scan later questions for approachable points, then return to harder items. Elimination is useful; avoid spending the entire contest on early questions.

## Exit ticket

1. Trace a loop or Boolean expression and explain **why** the output occurs.
2. Identify one error you made on the meet and how you would catch it next time.
3. Choose one skill to practice before the next meeting: loops, strings, arrays, postfix, trees, or test pacing.

**Success target:** Every student can trace a nested loop, explain pre/post-increment, and identify an array-bounds exception; advanced students can evaluate postfix notation and calculate BST height.
