# UIL Computer Science practice

Original preparation for written and programming contests, displayed by [Ms. Whitby’s Playground](https://www.mswhitby.com/playground/#/course/uil).

Edit `lessons/*.md` for student-facing prose, `programming/*.java` for starters, and `practice/written-01.json` for question choices and answer explanations. `course.json` supplies navigation and published programming cases. Lesson prose stays in Markdown.

The written set has 38 multiple-choice questions and two discrete-answer questions. It is a topic sample, not full coverage or an official UIL test. The first 15 positions follow the official sequence. All questions are original; no A+ materials are included.

The six programming activities include output-only, basic file-reading in a Java 26 IDE, and four browser computation drills. Browser practice uses an actual Java compiler and TeaVM; it is not the Java 26 contest environment. Use a Java 26 IDE for full contest preparation, files, and unsupported library features.

Official sources: [UIL Computer Science](https://www.uiltexas.org/academics/stem/computer-science) and [2026–2027 topic list](https://www.uiltexas.org/files/academics/UILCS-JavaTopicList2627.pdf).
