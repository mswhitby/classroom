# Print the team banner

UIL’s first programming problem requires output only. This original drill practices that habit: match every letter, space, and line break.

## Your task

Print these two lines, with no extra messages:

```text
WAGNER UIL
Think. Trace. Test.
```

Use `System.out.println()` for a line that ends with a newline. The class `TeamBanner` describes this program; `main` is Java’s entry point.

Run to inspect your output. Check compares it with the published example. A blank starter compiles, but its missing output still needs revision.
