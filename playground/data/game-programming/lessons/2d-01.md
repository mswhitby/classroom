# Work in a 2D scene

## Sprites and the camera

A SpriteRenderer displays a sprite. In a 2D scene, arrange objects in the XY plane and use an orthographic camera for a flat view. Sorting layers and order control which sprites appear in front; moving farther right changes x, not the sorting layer.

## Use the 2D physics family

Use Rigidbody2D and Collider2D components for 2D physics. They do not interact with the 3D Rigidbody and Collider family. Set up the puzzle room using the companion’s assets and instructions, then test its collisions.

## Slice and animate

The Sprite Editor can divide a sprite sheet into individual sprites. A sequence of frames forms an animation clip; an Animator plays clips according to its controller. Follow the animated-pet activity and inspect the clip frames.

## Separate the movement rule

The console practice uses arithmetic you have already learned. A horizontal offset adds to x; the unchanged y coordinate would still be handled separately in Unity. The console has no SpriteRenderer or Unity scene.

## Try tracing this example

```csharp
float newX = 3f + 2f;
return newX;
```

Before running it, predict which value changes. Then run a small test and explain what happened in your own words.
